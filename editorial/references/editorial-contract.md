# Editorial Editor 契约

## 不可变项

- 页数、画布、用户事实、数字 token、单位、期间、分母、来源、合成披露、主关系和结论强度；
- 原生可编辑性；
- 源 PPTX 不覆盖；
- OneSlide 信息贡献门槛继续生效。

## 单一编辑假设

每轮诊断只选择一个主问题。成组修改可以包含多个对象，但必须共同服务同一假设。示例：

```text
主问题：三个洞察卡远离对应数据，读者需要在图表和侧栏间反复跳转。
修改假设：将已有洞察文字移动到对应数据附近，并用字号、字重和文字颜色建立主次，阅读路径会更短。
```

## 允许操作

```text
move
resize
font-size
font-weight
text-align
text-color
```

所有操作必须有精确目标、源文件哈希、预期 bbox 和理由。V1.4 不开放任何文字或形状删除，也不得通过“缩短文字”删除限定、披露、口径或语义。数字 token 必须保持。非文本数据图形和关系几何不得移动或缩放。V1.4 也不开放形状填充、边线和层级操作，因为旧文件没有可验证的对象语义角色；这些操作不得依赖名称正则或调用者自证。

## 预算

- `standard`：一个候选，两次整页渲染；
- `targeted`：最多两个候选、三次整页渲染；第二候选必须是不同结构假设；
- 健康页面可以零修改；
- 已知硬缺陷修复不计为无收益美化，但仍必须完整回归。

## 接受与回退

接受候选需要同时满足：

1. 主问题在真实整页渲染中明显减轻；
2. 至少一个 rubric 维度改善，其他维度无材料性下降；
3. 来源和语义 token 保真；
4. 一页、原生可编辑、无裁切、无碰撞；
5. 信息贡献门槛通过。

任何硬回归都必须回退，不能用总分抵消。
