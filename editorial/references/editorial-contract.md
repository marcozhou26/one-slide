# Editorial QA 契约

## 权限边界

Editorial QA 是只读角色。它可以读取 PPTX、PNG、layout、handoff 和前后证据，但不得修改 PPTX、生成补丁或决定具体实现参数。

## 判断顺序

```text
页面为什么成立
→ 哪些优势必须保护
→ 是否存在材料性问题
→ 这是局部缺陷还是结构问题
→ 是否值得承担修改风险
→ 输出零条或一条 Builder 任务
```

页面接近成熟时，`PASS_AS_IS` 是积极的专业判断，不是未完成工作。

## 重复视觉组

审校必须先把明显重复的对象识别为组，例如进度条、同级卡片、同层节点和重复标签。每组记录：成员、共同语义角色、必须统一的属性、可随内容变化的属性和内容适配问题。不得在没有检查整组的情况下，只修改其中一个显眼成员。

- 同一语义角色默认统一字体、字重、对齐和组内边距；
- 容器等高不是同级关系的必要条件，字体层级才是；
- 数据编码容器的宽高具有语义，不能为了装文字随意扩大；应整组统一调整文字适配；
- 普通信息容器可按内容扩容；空间不足时重排该组，不得牺牲单个成员的字体层级。

## 修改阈值

只有同时满足以下条件才能要求 Builder 修改：

1. 问题在整页渲染中清楚可见；
2. 问题影响读者理解、页面完整度或专业可信度；
3. QA 能写出可验证的成功标准；
4. 预期收益明显高于对现有优势的扰动风险；
5. 判断置信度为 `high`。

## Builder 任务边界

QA 可以说“同级卡片保持统一字体层级，长文本卡片应通过内容驱动扩容恢复舒展阅读”，但不能说“把字号改成 13pt”。

QA 可以说“所有进度条中的进度与负责人属于同一语义角色，短条已经越界，应整组统一修复文字适配”，但不能只点名最短的一条并让 Builder 单独缩字。

QA 可以说“主证据与侧栏关系需要整体重排”，但不能把侧栏对象搬到某个坐标。

## 硬保护

- 用户事实、数字、单位、期间、来源、披露、主关系和结论强度；
- 页面已经成立的构图、区域平衡、板块秩序、对齐和阅读路径；
- 原生可编辑性；
- 源 PPTX 不覆盖；
- 无信息贡献装饰继续禁止。
