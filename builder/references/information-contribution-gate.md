# 信息贡献门槛

本文件是 OneSlide 所有可见对象是否允许进入页面的单一事实来源。进入绘制、套用模板、视觉修复和最终 QA 时都必须执行。

## 核心规则

每一个读者可见对象都必须能回答：它让读者多知道了什么，或帮助读者识别了什么关系？如果答案只是“更好看”“更像模板”“填满空白”“增加层次感”，该对象必须删除。

允许的贡献只有以下六类：

1. 信息与语境：标题、必要且不重复的限定、对象、范围或状态；
2. 证据与数据编码：数值、图形、颜色、位置、大小或形状直接编码证据；
3. 关系与结构：坐标轴、必要网格、连接线、分组框或容器帮助读者理解真实关系；
4. 定义与来源：单位、期间、分母、口径、样本、来源、合成数据披露；
5. 行动与条件：由页面证据支持的动作、风险、条件或待确认项；
6. 必要身份：用户明确要求的品牌名称或标识。品牌身份不是添加装饰色带、标题饰线或重复口号的理由。

## 明确禁止

- 页面顶部或底部没有文字、数据或结构作用的深色带、色条、横条和色块；
- 标题上方的 eyebrow、kicker、overline、supertitle 或其他眉标，即使它重复写了栏目名、主题词或英文标签；
- `heading-rule`、`title-accent`、品牌装饰线、角标、圆点、花纹和纯视觉分隔线；
- 只为“更精致”添加的图标、阴影、渐变、描边、纹理和网页式组件；
- 没有承载内容或结构关系的空卡片、空面板、空容器和占位块；
- 与标题或邻近文字重复、没有新增对象、范围、定义、证据或行动含义的标签；
- 为填满画布而添加的建议、指标、基准、说明或任何装饰对象。

## 不得误杀的结构对象

没有文字不等于没有信息贡献。数据柱、散点、区间带、连接线、坐标轴、必要网格线、关系箭头、对齐边界和承载真实内容的分组容器可以保留，因为它们编码数据或关系。判断依据是语义作用，不是对象类型。

带状容器只有在内部承载读者需要的信息，并且容器确实帮助组织这组信息时才能保留。`bottom-strip` 等名称本身既不自动通过，也不自动失败。

## 模板处理

模板中的可见形状受同一门槛约束。不得以“品牌模板原样保留”为理由绕过检查。检测到纯装饰形状时，默认阻断模板套用并返回稳定错误，不静默保留，也不擅自替用户修改品牌模板。

## 阻断状态

```text
DECORATIVE_ELEMENT_BLOCKED
DECORATIVE_TOP_BAND_BLOCKED
EYEBROW_BLOCKED
TEMPLATE_DECORATION_BLOCKED
```

任何一项出现都不得进入 `delivery/`。删除或改写对象后，重新执行 layout、渲染、PowerPoint 打开和整页视觉检查。
