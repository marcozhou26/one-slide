# 引用资料清单模块

适用：把 OneSlide 实际使用过的外部资料和可引用文件整理成一页编号清单，方便读者核查来源。正式模块 ID 为 `reference-list`，`diagram.type` 必须同名。

## 与其他页面的边界

- 本模块不是数据明细表。用户只需要展示原始明细时，使用原生表格或现有表格能力；
- 本模块不是补充分析页。带有独立判断、复杂关系或主图的内容继续作为普通 OneSlide 页面处理；
- 本模块只列实际进入来源记录的资料，不编造、不补写不存在的作者、机构、日期、标题或链接；
- 同一来源在多个页面被使用时合并为一项，并保留全部正文页回链；
- 每次仍只生成一页。去重后超过 8 项时返回 `SINGLE_SLIDE_SCOPE_OVERLOAD`，不得缩小到不可读字号或自动生成第二页。

## 输入契约

- `references`：2–8 项，按首次实际使用顺序排列；
- 每项包含唯一 `id`、页面可见的 `citation`、页面可见的 `locator`、稳定 `canonical_key` 和 `source_ids`；
- `citation` 保留已有作者或机构、标题、出版或发布日期等资料，不推测缺失字段；
- `locator` 使用 DOI、公开 URL、稳定文献编号或干净文件名，不得出现本机绝对路径、本地文件 URL、用户名或内部缓存位置；
- `supporting_pages` 可选，用于列出该资料支持的正文页；缺失时不阻塞单页生成；
- `source_note` 说明本页的收录范围，例如“仅列本报告实际引用资料，按首次出现顺序排列”。

Producer 应优先从一个或多个 `provenance-ledger.json` 汇总，不要求用户重新抄写引用清单。只收录带可核验引用元数据的 `externally_verified` 条目，以及明确带引用元数据的 `user_supplied` 文件；跳过计算、稳定推导、合成内容和普通用户提示词锚点。

## 页面与编辑性

页面使用单列、从上到下的编号列表。每项最多两层：第一层为引用正文，第二层为定位信息和可选正文页回链。仅使用原生 PowerPoint 文本、线条和形状；不添加卡片、图标、缩略图、关系图、洞察栏或装饰性统计。

验收至少覆盖：完整来源记录、跨页重复来源去重、稀疏自然语言路由、缺少来源记录、缺少引用标题或定位信息、超过 8 项、缺少非阻塞样式字段和异常 JSON。生成 PPTX 后检查恰好一页、16:9、0 图片对象、字体不小于 12pt、单列阅读顺序和 Microsoft PowerPoint 实际打开。
