# 图表＋洞察栏模块

适用：4–8 个时点或类别、两组可比柱形数据、一组比值或指数，以及三条有数据依据的洞察。

必需输入：4–8 个带唯一 `id` 的类别；两组带唯一 `id`、相同明确单位、等长且非负的柱形数列；一组带唯一 `id`、明确单位和固定 `axis_min/axis_max` 的比值或指数数列；三条洞察及其 `anchor.series_id + anchor.category_id`；所有可见文字和数据均有来源。如有行动结论，也必须来自原文。

缺失或冲突：数组长度不一致、柱形单位不可比、负柱值、次坐标范围缺失或不包含全部比值、洞察无法锚定到明确数据点时停止。不得由 Renderer 猜测洞察要指向哪根柱或哪个折线点。

禁止：为了让图好看按当前最小/最大值临时拉伸次坐标、改变坐标、补齐年份、外推趋势或替客户写 So What。折线点必须显示原始数值与单位。
