# 小倍数比较模块

适用：3–9 个对象在同一指标、单位、有序时期和共享 Y 轴上重复比较。支持 `line` 趋势或 `column` 分期柱形；基准序列可选。

## 输入契约

| 输入 | 程度 | 要求 | 缺失或冲突处理 |
| --- | --- | --- | --- |
| `series_type` | required | `line` 或 `column` | 不根据“趋势”等文字猜测；缺失时 `DATA_CONTRACT_FAIL` |
| `metric`、`unit` | required | 来源支持的可见指标和单位 | 单位缺失或冲突时停止，不拼接不同口径 |
| `periods` | required | 3–12 个有序、来源支持的时期 | 面板长度不一致时停止 |
| `scale.min/max` | required | 有限数值且 `min < max`；覆盖全部面板和基准 | 禁止各格独立缩放或自动截断异常值 |
| `benchmark` | optional | 与时期等长；提供时同时需要 `benchmark_label` 和 `benchmark_source_ids` | 缺失时不画基准，不阻塞主比较 |
| `panels` | required | 3–9 个；每个含标签、等长数值、摘要、可见分类、结构化状态和来源 | 数值越界、时期不等长或状态异常时停止 |
| `classification_state` | required | `invest`、`maintain`、`watch`、`exit` | 状态决定视觉语义；禁止从可见中文措辞猜颜色 |
| `insights`、`conclusion` | optional | 仅解释主图已有证据 | 缺失时缩小支持区，不自动补写 |

## 视觉语义

- 所有面板共用同一指标、单位、时期和 Y 轴范围；页面上明确显示共享刻度。
- `invest` 为蓝色强调，`maintain` 为深蓝，`watch` 为灰色，`exit` 为橙色；可见分类文字不参与颜色推断。
- 每格显示首末时期、首末值和必要的中间趋势；基准存在时使用统一灰色虚线并显示名称。
- `line` 使用原生折线和端点，`column` 使用共享零点或声明的共享下界绘制原生矩形。
- 3–4 个面板使用紧凑两列或三列；5–9 个面板使用三列。不得为填满空格复制对象。

## 阻塞边界

- 对象使用不同指标、单位、时期或量表时，不进入本模块。
- 需要每格独立尺度、第二个主图或面板专属分析口径时，进入带门禁的直接编排或返回 `MODULE_COVERAGE_GAP`。
- 地图、组织关系、流量或成熟度阶段不因“多个对象”被误路由到小倍数。
