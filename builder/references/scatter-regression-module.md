# 双连续变量线性关系模块

适用：帮助读者判断两个连续变量在当前样本中的关系方向、线性强度、偏离总体趋势的观测，以及结论可以解释到什么范围。正式模块 ID 为 `scatter-regression`，`diagram.type` 必须同名。V1 只执行带截距的一元普通最小二乘线性拟合，不扩展到对数、指数或多项式模型。

## 与其他模块的边界

- 本模块要求逐条 x/y 原始观测，不接受只有相关系数、斜率或汇总均值的输入；
- `histogram` 回答单个连续指标的分布，本模块回答两个连续指标的共同变化；
- `chart-insight` 处理时间序列或一般图表洞察，不复算一元线性模型；
- 页面如还需独立的分组比较、时间趋势或因果路径，省略三个模块字段并进入 `direct_composition`，或返回单页范围超载；
- 相关或回归只描述样本内线性关联，不得改写成因果，不得补造 p 值、置信区间或统计显著性。

## 输入契约

- `x_metric`、`y_metric`：两个轴的指标名称；`x_unit`、`y_unit`：各自单位；
- `period`、`population`、`sample_definition`、`source_note`：期间、总体、样本粒度和来源说明；
- `observations`：8–200 条逐条原始记录，每条包含唯一 `id`、`x`、`y` 和 `source_ids`；缺失值显式保留为 `null`，可选 `label` 用于页面异常点标注；
- `sample`：原始总数、有效配对数、缺失配对数和精确重复对数；
- `method=ordinary_least_squares_with_intercept`；
- `handling`：V1 固定为配对缺失剔除、精确重复作为独立观测保留、异常点保留并标注；
- `outlier_rule`：页面可见的异常点选择规则；V1 使用绝对残差排序并标注前 1–3 个有效观测；
- `highlight_ids`：必须与按绝对残差复算得到的前 N 个观测一致，且相应记录必须提供可见 `label`；
- `statistics`：声明的 `slope`、`intercept` 和 `r_squared`，由 Builder 从有效原始观测复算；
- `reconciliation_rule`：页面可见的复算、容差和显示舍入规则；
- `interpretation_boundary`：页面可见的“样本内关联不等于因果，外推需另行验证”；
- `insights`：1–3 条由数据支持且不越过解释边界的洞察；可选 `conclusion` 和 `disclosure`。

## 缺失、重复、离群与复算门禁

- 有效配对少于 3 条时返回 `REGRESSION_SAMPLE_TOO_SMALL`；正式产品页要求至少 8 条有效配对；
- x 或 y 零方差时返回 `REGRESSION_ZERO_VARIANCE`；
- 缺失 x 或 y 的记录保留在原始观测中，但只做配对剔除，样本统计必须对平；
- V1 不自动删除精确重复；声明的重复对数必须与原始观测复算一致；
- 异常点继续参与拟合；`highlight_ids` 必须按绝对残差排序复算，不能凭视觉挑选支持结论的点；
- 斜率、截距和 R² 使用未舍入原始值复算，绝对误差不得超过 `1e-6`；页面显示斜率和截距两位小数、R² 三位小数；
- 不接受 `through_origin`、多项式、对数或指数方法；不接收或展示未由输入支持的显著性结论。

## 页面与编辑性

主图使用原生 PowerPoint 椭圆点、直线、坐标轴、网格线和文本。回归线使用与数据点不同的线型；异常点除颜色外必须有原生文字标签和引线。页面同时显示公式、R²、样本数、缺失/重复处理、异常点规则、来源/期间/总体和解释边界。验收必须覆盖完整、稀疏自然语言、关键缺失、模糊冲突、非阻塞样式缺失、异常 JSON、样本不足、零方差、统计对平和正式 Producer handoff。
