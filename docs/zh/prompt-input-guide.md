# 怎样给 OneSlide 写一个好提示词

想让 OneSlide 做出一页清楚、好看、可编辑的 PPT，你不需要懂图表名称，也不用规定每个元素放在哪里。只要把下面六件事说清楚。

## 1. 这页讲什么

用一句话说明主题，并尽量把范围缩到一个问题。

例如：分析今年各产品线的收入变化，找出增长主要来自哪里。

## 2. 这页给谁看

说明读者是谁，以及希望他看完后做什么。

例如：给管理层看，希望他们决定明年优先投入哪条产品线。

## 3. 最想让读者记住什么

写出这一页最重要的一句话。它可以是已经确认的结论，也可以是希望 OneSlide 根据材料帮助提炼的判断。

例如：今年的增长主要来自数字订阅，项目交付收入虽然增长，但利润贡献正在下降。

## 4. 必须放进页面的内容

列出关键数字、事实、对象和名称。数据较多时，可以直接附上 Excel、CSV、Word、PDF 或 Markdown 文件。

同时说明：

- 数据是什么时间的；
- 数字使用什么单位；
- 哪些内容最重要；
- 哪些内容不能省略。

## 5. 希望读者看见什么关系

用日常语言描述重点关系即可。例如：

- 比较几个方案的差异；
- 看过去三年的变化趋势；
- 找出谁高、谁低、差距多大；
- 展示一个流程如何运转；
- 展示部门之间的汇报关系；
- 说明问题从哪里产生、会影响什么。

如果你不确定用什么图，不必指定，让 OneSlide 根据内容选择。

## 6. 其他要求

可以补充品牌颜色、参考页面、需要强调或回避的内容，以及数据来源。没有特别要求可以不写。

---

## 可直接复制的提示词

```markdown
请使用 OneSlide 生成一页 16:9、原生可编辑的 PowerPoint。

### 页面主题
[这页讲什么，只写一个主要问题]

### 目标读者和用途
- 给谁看：[读者]
- 希望读者看完后：[理解、判断、比较、批准或采取什么行动]

### 最重要的一句话
[这页最想让读者记住的结论；如果还没有结论，请根据材料提炼]

### 必须使用的内容
- [关键事实、数字或对象 1]
- [关键事实、数字或对象 2]
- [关键事实、数字或对象 3]

附件或数据来源：
[文件名、链接或资料说明]

数据时间、单位和口径：
[例如：2026 年上半年；单位为万元；收入为不含税口径]

### 希望呈现的重点关系
[例如：比较四条产品线的收入、增速和利润贡献，并突出增长与利润表现不一致的产品线]

### 页面要求
- 重点突出，阅读顺序清楚。
- 保留必要的数据来源、时间、单位和口径。
- 只使用材料中能够支持的事实和结论。
- 如果内容超过一页，请先保留最重要的信息，并给出拆页建议。

### 风格偏好（可选）
[颜色、品牌、参考页面或其他要求]
```

## 写提示词时记住三句话

1. 一页只解决一个主要问题。
2. 先说清楚想表达的关系，再考虑用什么图。
3. 材料越具体，OneSlide 越容易做出准确的页面。
